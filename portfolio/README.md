# PORENA 기획 포트폴리오

게임·시스템 기획 지원용 사이트의 로컬 검토본입니다. 기획 사례, 라운드별 규칙, 담당 역할과 개발 기록을 소개합니다.

## 실행

Node.js가 설치된 환경에서 저장소 루트에서 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
node portfolio/serve.mjs
```

브라우저에서 `http://127.0.0.1:4186/`을 엽니다. 서버는 이 PC에서만 접속할 수 있도록 설정돼 있습니다.

`index.html`을 직접 열어도 사이트를 확인할 수 있습니다. 공개 호스팅 설정은 포함하지 않았습니다.

## 파일

- `index.html`: 소개, 담당 역할, 기획 사례, 게임 규칙, 작업 방식
- `site.js`: 사례와 라운드별 설명 전환
- `style.css`: PC·모바일 화면 스타일
- `assets/`: 게임 배경과 개발 QA 화면
- `review/`: 작업 과정에서 저장한 검토용 화면. 최신 문구 확인은 `editorial-desktop.jpg`, `editorial-mobile.jpg` 참고
- `../product_doc/portfolio/`: 구성, 기여 근거, 문구 검토, 검증 기록

사례의 수치와 게임 규칙은 페이지에 표시된 개발 기록 시점을 기준으로 합니다. 이름·참여 기간·연락처는 제출 전에 보완해야 합니다.
