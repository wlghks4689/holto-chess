# PORENA 레이아웃 점검 — 2026-09-20

## 범위와 검증 수준

이번 작업은 조사이며 UI 수정·커밋·배포는 하지 않았다. 게임 규칙 변경도 없다.
로컬 개발 서버의 드래프트 미리보기와 싱글플레이로 점검했으며 운영 멀티플레이 방은 생성하지 않았다.
R4 드래프트는 320, 390, 520, 700, 701, 768, 1024, 1440px에서 DOM 치수를 확인했다.
메인·모드 선택·R1 룰 안내·상점·헤즈업 쇼다운은 로컬 화면을 확인했다.
관전, 탈락 안내, 재경기, R3 배치, 최종 순위, 대전기록은 관련 구성요소와 공통 스타일을 검토했으나 모든 상태를 실제 멀티플레이에서 시각 검증한 것은 아니다.
따라서 전 화면 실기기 검증 완료로 해석하면 안 된다. iOS Safari, 가로 모드, 긴 닉네임, 큰 글꼴 설정은 추가 검증이 필요하다.

## 코드상 확인 및 추가 재현 대상

1. **공통 패널 기본 여백 없음 — 높음.** styles.css의 `.panel`은 테두리·배경만 정의한다. inventory, market 등은 자체 padding이 있지만 `.run-loadout`, `.eliminated-priority`, `.rematch-panel`은 같은 수준의 외곽 내용 여백이 없다. 개별 패널마다 누락되는 구조다.
2. **관전 배너 상단 겹침 — 중간.** nav 최소 높이는 기본 78px/620px 이하 63px인데 spectator-banner top은 70px/639px 이하 62px이다. 특히 621~639px에서 nav 78px와 banner top 62px의 차이가 16px이다. 스크롤한 관전 상태에서 가려짐 재현 필요.
3. **R3 배치의 중간 너비 — 높음.** 480px 이하 1열 보정은 이미 있으므로 이를 누락으로 판단하면 안 된다. 481~620px 두 게임 병렬 상태에서 각 카드 65px×2+간격6px+내부 여백18px가 필요하다. 바깥 inventory padding까지 적용된 최소 너비 구간을 측정해야 한다.
4. **관전 중 자기 지시 문구 — 중간.** 관전 대상 view를 동일 OpenDraftPanel에 전달하므로 `내 보유 카드`, `공개 카드 한 장을 선택하세요`, `내 차례`가 관전자에게도 나올 수 있다. 조작은 disabled지만 표시 문구와 의미가 불일치한다.
5. **최종 결과 481~620px — 중간.** 7열을 유지하며 고정 열만 251px이고 gap과 padding이 추가된다. 닉네임 칸이 좁아질 수 있다. 480px 이하 재배치는 이미 있으므로 경계 바로 위와 긴 이름을 중점 확인해야 한다.
6. **좁은 화면의 정보 밀도 — 중간.** draft-rule은 520px 이하에서 설명 배지를 3줄로 확장한다. R4 보유 카드와 16장 공개 풀까지 쌓여 주요 선택 영역이 길어진다. 참가자별 카드와 현재 선택자 안내를 포함한 전체 높이 검증 필요.
7. **개발용 고정 모드 버튼 — 낮음, 운영 제외.** mode-switch는 z-index 90으로 우하단에 고정되어 하단 콘텐츠를 덮을 수 있으나 DEV에서만 렌더링된다. 운영 버그와 혼동하지 않아야 한다.
8. **전환 연출과 안내 배치 — 높음.** 탈락 안내와 관전 전환 컨트롤이 CinematicGate 안에 있다. 연출·서버 단계 전환 결함과 결합하면 안내를 못 보는 문제를 여백만 고쳐서는 해결할 수 없다. 이전에 재현한 진행 결함과 별도로 다뤄야 한다.

## 권장 수정 순서와 검수 기준

1. 패널 콘텐츠 여백을 공통 토큰으로 정하고, 헤더·본문·하단의 시작선을 맞춘다. 전역 padding 추가만으로 기존 패널의 여백을 이중 적용하지 않는다.
2. R4 보유 카드 영역을 명명된 구성요소로 분리하고 제목·카드·도움말의 간격을 지정한다.
3. 드래프트의 JSX와 표시 순서를 통일한다. CSS order로 순서를 숨겨서 관리하지 않는다.
4. 8열 전환은 실제 카드 최소폭과 내부 여백을 기준으로 결정한다. 700/701px 경계만으로 나누지 않는다.
5. 가격 행을 내용 높이에 맞추고 소유자 이름과 별도의 간격을 확보한다.
6. 참가자 목록과 현재 선택 안내에 동일한 본문 좌우 여백을 부여한다.
7. 관전 전용 문구와 선택 대상 이름을 분리하여 읽기 전용 상태를 명확히 한다.
8. 쇼다운과 일반 화면에 동일한 외곽 여백을 적용하되 좁은 화면의 카드 가독성을 재검수한다.
9. 관전 배너의 sticky top을 nav 높이와 같은 기준으로 관리한다.
10. R3 배치는 카드 최소폭을 기준으로 1열 전환점을 정하고, 481px 및 620px 경계에서 카드가 겹치지 않는지 검사한다.
11. 최종 순위표는 긴 닉네임·족보명·큰 BB를 넣고 480/481/620px에서 검사한다.
12. 탈락·재경기·타이브레이크 안내·룰 팝업은 표시 길이와 스크롤, 하단 버튼 접근성까지 별도 검수한다.

공통 통과 조건: 문서 가로 넘침 없음, 카드가 자신의 칸을 초과하지 않음, 타이머 및 버튼 잘림 없음, 제목·본문 시작선 일치, 고정 요소가 주요 액션을 가리지 않음. 관전은 조작 가능 화면과 문구를 구별한다.
