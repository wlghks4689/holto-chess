# 어빌리티 규칙 및 판정

이 문서는 캐릭터 이름·초상 없이 어빌리티 ID를 플레이어에게 배정하고, 서버가 확정된 규칙대로 효과를 판정하는 기준이다. 카드의 KO/EN 설명은 표시용이며, 아래 규칙과 서버 코드가 동작의 정본이다.

## 배정과 권한

- 현재 12개 어빌리티 중 8개를 경기 시작 전에 뒷면 카드 선택으로 배정한다(미선택 4개). 선택 순서는 서버가 섞어 확정하고, 한 어빌리티는 한 플레이어만 받을 수 있다. 저장된 이전 경기의 선택 덱은 서버 `slotCount`를 따른다.
- 시간 만료·연결 해제 시 서버가 남은 카드 중 하나를 선택한다. 재접속은 서버의 선택·순서·타이머를 그대로 복원한다.
- 카드 선택과 모든 효과 판정은 서버 권한이다. 클라이언트는 `abilityId`를 지정하거나 보상·가격·자격을 제출할 수 없다.
- 매치 효과는 정규 보드의 결과만 판정한다. R2 두 RUN은 각각 별도 정규 매치다. 타이브레이크 보드 자체는 매치 능력 보상을 만들지 않지만, 생존 확정 후 보류된 라운드 효과(자본주의·독주자)는 정산한다.

## 확정 효과와 경계

| ID | 효과와 서버 판정 |
| --- | --- |
| `royal-blood` | 시작 카드 1장을 A/K/Q/J/T에서 지급한다. 해당 랭크는 상점과 공개 드래프트에서 기본 가격의 절반, 소수점 버림으로 산다. Q는 15→7BB. |
| `target-sniper` | 최초 지급 카드가 소유 중이고 최상위 동급 BEST5 중 그 카드를 포함하는 합법 조합이 있으며 스트레이트 이상이면 매치당 +15BB. 승패·Split과 무관. R2 RUN별 판정. 같은 카드 재획득으로 최초 카드가 현재 소유 카드에 포함되면 자격 회복. |
| `underdog` | R5 정규 결과의 BEST5에 2가 있고 족보가 스트레이트 이상이면 최종 점수 +20P. 승패 무관. |
| `first-class` | R2/R4 공개 드래프트에서 순위와 무관하게 첫 선택. 다른 플레이어의 상대 순서는 기존 순위 정렬을 유지한다. |
| `golden-hand` | 개인 상점이 있는 라운드에 상점 슬롯 +1. 판매 환급은 카드 기본 가격의 100%이며 시작 카드 판매도 동일하다. 개인 상점이 없는 R2에는 슬롯 효과 없음. |
| `trader` | 개인 상점 리롤·카드 잠금 비용 0BB, 개인 상점 페이즈별 리롤 +1. 개인 상점이 없는 R2에서는 리롤·잠금 효과 및 추가 횟수 미적용. |
| `predator` | 정규 매치 단독 승리 때 연승을 1 올린다. 2연승부터 각 승리에 +10BB. 연승은 라운드를 넘어 유지하고, Split 또는 패배는 0으로 초기화한다. 타이브레이크 승리는 기록하지 않고 정규 Split 뒤 타이브레이크 승리도 발동하지 않는다. |
| `architect` | 정규 매치의 최종 족보가 정확히 풀하우스이면 +30BB. 상위 족보는 제외. 승패·Split과 무관. R2 RUN별 판정. |
| `capitalism` | 생존한 라운드의 결과·탈락 정산 후 보유 BB의 20%를 소수점 버림하여 지급한다. 탈락 라운드는 제외한다. 한 라운드당 한 번만 지급하며 R5 생존자에게도 적용. |
| `zero-risk` | 서버가 정규 보드를 만들기 전에 계산해 매치 결과에 고정한 R1~R4 승률 raw 값이 60% 이상이고 정규 매치에서 단독 패배하면 +20BB. Split·R5·타이브레이크는 제외. UI는 동일 결정적 계산을 사용하고 각 좌석 승률을 정수 내림 표시한다. |
| `quad-core` | R5 최종 BEST5의 포카드 4장에 최초 지급된 정확한 카드가 포함되면, ICM 배분 완료 후 본인의 순위 점수만 두 배. 키커·판매로 부재·다른 카드는 제외. 같은 카드 재획득은 자격 회복. |
| `front-runner` | 모든 매치·탈락·이자 정산 후 R1~R4 생존 순위 1위, R5 파이널 매치 place 1의 보유자에게 각각 +3/+4/+5/+6/+7P. 라운드당 한 번. |

### 표시 이름과 내부 ID

최신 한국어 이름은 왕가의 혈통(`royal-blood`), 타겟 스나이퍼(`target-sniper`), 언더독(`underdog`), 퍼스트 클래스(`first-class`), 황금의 손(`golden-hand`), 트레이더(`trader`), 포식자(`predator`), 건축가(`architect`), 자본주의(`capitalism`), 제로리스크(`zero-risk`), 쿼드 코어(`quad-core`), 독주자(`front-runner`)다. 과거의 “아키텍트”는 현재 “건축가”이며 내부 ID `architect`는 바꾸지 않는다.

### 자본주의 — 라운드 정산

- 대상은 최종 탈락 판정 이후 생존한 자본주의 보유자다. 미보유자·이전/현재 라운드 탈락자는 제외하며 R5 생존자도 포함한다.
- 기준은 해당 라운드의 정규 매치 보상 및 BB 능력 보상까지 반영한 현재 `stackBB`다. `floor(stackBB × 0.2)`를 더한다. 0~4BB는 0, 5BB는 1, 57BB는 11, 99BB는 19, 100BB는 20BB다. 시작 BB나 RUN별 BB를 따로 사용하지 않는다.
- R1은 세 매치 종료 후, R2는 두 RUN 종료 후 한 번 정산한다. R3/R4는 최종 생존·탈락 확정 후 정산한다. R3 생존 타이브레이크 대기 중에는 전원 보류하고, 타이브레이크 탈락 처리 → `survival` 해제 → 이자 → 독주자 순으로 처리한다. 타이브레이크 승리 보상이 아니다.
- R5는 순위/ICM 및 기존 능력 정산 후 이자, 그 뒤 독주자와 최종 집계 순이다. 이자가 이미 완료된 ICM 배분을 다시 계산하지 않는다.
- `abilityInterestRounds`가 라운드 중복 실행을 막는다. 지급액이 0이거나 대상이 없어도 정산 완료를 기록하며, JSON 저장/복원 이후에도 재지급하지 않는다. `survival` 대기 방어는 유지한다.
- 실제 양수 지급만 `abilityEvents.reason = round-interest`와 `abilityTotals.bb`에 기록한다. 이 이벤트는 매치 ID 없는 라운드 보상이다. R1/R2/R3 정규 매치·RUN 보상 원장은 이미 확정된 매치 보상을 유지하며, 라운드 결과/플레이어 뷰/최종 BB는 이자를 포함한 실제 잔액을 사용한다. R3 생존 매치 등 이자 뒤에 캡처하는 원장의 `afterBB`에는 이자가 포함되므로 이벤트 금액을 다시 더하지 않는다.
- 싱글과 멀티 방 전이는 같은 엔진을 사용한다. 2026-09-30 수정은 R2 호출 누락과 R3 상태 해제 순서만 바로잡으며 수치·자격·중복 방어를 변경하지 않는다.

### 쿼드 코어 — R5 순위 점수

- R5 `final` 결과의 족보가 정확히 `QUADS`이고, 소유 중인 `firstCardId`가 최종 BEST5의 포카드 랭크 4장 중 하나여야 한다. 키커, 상위 족보, 다른 라운드, 같은 랭크의 다른 문양은 불인정한다.
- 판매하여 없으면 제외한다. 정확히 같은 카드의 재획득은 판정 자격을 회복하는 것이며, 이미 받은 보상을 다시 지급하는 뜻이 아니다.
- 기존 순위/동률 ICM 배분이 끝난 뒤 본인에게 배분된 양수 순위 점수만 추가로 한 번 더 준다. 단독 순위 기본 20/12/5/3P는 40/24/10/6P가 된다. 동률은 ICM으로 배분된 본인 몫만 두 배다.
- 누적 점수, 족보 보상, BB, 다른 능력 보상, 최종 총점 전체는 배가하지 않는다. `r5-quad-core` 이벤트에 추가분만 기록하고 같은 매치·플레이어의 이벤트로 중복 지급을 막는다.

### 독주자 — 라운드 선두 보너스

- R1~R4는 생존자 중 누적 승점 → 보유 BB → 기존 안정적 좌석 순으로 정렬한 첫 1명만 대상이다. 이자까지 정산한 보너스 지급 직전 순위로 판정하며 탈락자는 제외한다.
- R5는 최종 총점 순위가 아닌 파이널 매치의 확정 `place === 1`을 사용한다. 공동 1위도 자격이 있다(각자 독주자 보유 조건 필요). 기존 ICM/순위 배분을 변경하지 않는다.
- 대상 집합은 보너스를 더하기 전에 고정한다. R1~R5 보너스는 각각 3/4/5/6/7P이며 `round-leader`에 추가분만 기록한다. `abilityLeaderRounds`로 라운드당 한 번만 처리하며, 자격자가 없어도 재판정하지 않는다. 매치·그룹·생존 타이브레이크 진행 중에는 지급하지 않는다.

## 검증 경계

- 동급 최상위 족보·키커를 유지하는 합법 BEST5가 여러 개면, 조건 카드가 포함된 조합이 하나라도 있을 때 자격을 인정하고 그 조합을 사용/표시한다.
- 정규 Split은 승패형 효과(연승, 패배 보상)를 발동시키지 않는다. 승패 무관 메이드 효과는 조건 충족 시 발동한다.
- R2 RUN 자격은 각 RUN의 출전 카드·보드·사전 승률을 따로 사용한다. 타이브레이크는 매치 능력 보상 및 연승 판정에 사용하지 않는다. 최종 생존 확정 후 라운드 효과 정산과 구분한다.
- 서버는 보드 생성 전에 raw 승률과 60% 자격을 `MatchResult`에 고정한다. 미리보기와 서버는 같은 결정적 계산·알려진 카드 입력을 사용하며, UI는 양 좌석 값을 각각 정수 내림한다. 따라서 raw 59.xx%는 60%로 표시되지 않는다. 재접속, 언어 전환, 숨겨진 미래 보드는 자격을 바꾸지 않는다.
- 이자/보상과 탈락 스냅샷 순서를 보존하여 탈락 라운드 이자는 없고, 최종 BB에는 실제 지급 내역만 반영한다.
- 현행 12종 목록은 `src/game/abilities.ts`의 `ABILITY_IDS`와 대조한다. `capitalism.test.ts`는 R1~R5·R3 생존 경계·절삭·저장/복원 중복·방 전이·잔액/이벤트를 검증하며, `quadCore.test.ts`와 `frontRunner.test.ts`는 각 능력의 조건·예외·중복을 검증한다. 실행 증거: [2026-09-30 QA](qa/2026-09-30-capitalism-interest.md).

## 사용자 승인 근거

- 카드 효과 문구 및 효과 범위: 사용자 제공 어빌리티 설명.
- Q 15BB 반값은 소수점 버림하여 7BB.
- 동급 최상위 BEST5에 조건 카드가 들어가는 조합이 있으면 타겟 스나이퍼를 인정하고 그 조합을 표시.
- 자본주의는 탈락한 라운드에 이자를 지급하지 않음.
- 승패 무관 메이드 효과와 승패형 효과의 Split/타이브레이크 경계를 분리.
- 쿼드 코어·독주자: [DECISIONS.md](DECISIONS.md)의 ABILITY-011/012. 초기 10종 및 쿼드 코어 추가 당시 11종 기록은 역사이며, 현행 목록은 12종이다.
