# 어빌리티 규칙 및 판정

이 문서는 캐릭터 이름·초상 없이 어빌리티 ID를 플레이어에게 배정하고, 서버가 확정된 규칙대로 효과를 판정하는 기준이다. 카드의 KO/EN 설명은 표시용이며, 아래 규칙과 서버 코드가 동작의 정본이다.

## 배정과 권한

- 10개 어빌리티 중 8개를 경기 시작 전에 뒷면 카드 선택으로 배정한다. 선택 순서는 서버가 섞어 확정하고, 한 어빌리티는 한 플레이어만 받을 수 있다.
- 시간 만료·연결 해제 시 서버가 남은 카드 중 하나를 선택한다. 재접속은 서버의 선택·순서·타이머를 그대로 복원한다.
- 카드 선택과 모든 효과 판정은 서버 권한이다. 클라이언트는 `abilityId`를 지정하거나 보상·가격·자격을 제출할 수 없다.
- 매치 효과는 정규 보드의 결과만 판정한다. R2 두 RUN은 각각 별도 정규 매치이며, 타이브레이크 보드는 능력 보상을 만들지 않는다.

## 확정 효과와 경계

| ID | 효과와 서버 판정 |
| --- | --- |
| `royal-blood` | 시작 카드 1장을 A/K/Q/J/T에서 지급한다. 해당 랭크는 상점과 공개 드래프트에서 기본 가격의 절반, 소수점 버림으로 산다. Q는 15→7BB. |
| `target-sniper` | 최초 지급 카드가 소유 중이고 최상위 동급 BEST5 중 그 카드를 포함하는 합법 조합이 있으며 스트레이트 이상이면 매치당 +15BB. 승패·Split과 무관. R2 RUN별 판정. 같은 카드 재획득으로 최초 카드가 현재 소유 카드에 포함되면 자격 회복. |
| `underdog` | R5 정규 결과의 BEST5에 2가 있고 족보가 스트레이트 이상이면 최종 점수 +20P. 승패 무관. |
| `first-class` | R2/R4 공개 드래프트에서 순위와 무관하게 첫 선택. 다른 플레이어의 상대 순서는 기존 순위 정렬을 유지한다. |
| `golden-hand` | 개인 상점이 있는 라운드에 상점 슬롯 +1. 판매 환급은 카드 기본 가격의 100%이며 시작 카드 판매도 동일하다. 개인 상점이 없는 R2에는 슬롯 효과 없음. |
| `trader` | 개인 상점 리롤·카드 잠금 비용 0BB, 개인 상점 페이즈별 리롤 +1. 개인 상점이 없는 R2에서는 리롤·잠금 효과 및 추가 횟수 미적용. |
| `predator` | 정규 매치 단독 승리 때 연승을 1 올린다. 2연승부터 각 승리에 +10BB. 연승은 라운드를 넘어 유지하고, Split 또는 패배는 0으로 초기화한다. 타이브레이크 승리는 기록하지 않고 정규 Split 뒤 타이브레이크 승리도 발동하지 않는다. |
| `architect` | 정규 매치의 최종 족보가 정확히 풀하우스이면 +30BB. 상위 족보는 제외. 승패·Split과 무관. R2 RUN별 판정. |
| `capitalism` | 생존한 라운드의 결과·탈락 정산 후 보유 BB의 20%를 소수점 버림하여 지급한다. 탈락 라운드는 제외한다. 한 라운드당 한 번만 지급하며 R5 생존자에게도 적용. |
| `zero-risk` | 서버가 정규 보드를 만들기 전에 계산해 매치 결과에 고정한 R1~R4 승률 raw 값이 60% 이상이고 정규 매치에서 단독 패배하면 +20BB. Split·R5·타이브레이크는 제외. UI는 동일 결정적 계산을 사용하고 각 좌석 승률을 정수 내림 표시한다. |

## 검증 경계

- 동급 최상위 족보·키커를 유지하는 합법 BEST5가 여러 개면, 조건 카드가 포함된 조합이 하나라도 있을 때 자격을 인정하고 그 조합을 사용/표시한다.
- 정규 Split은 승패형 효과(연승, 패배 보상)를 발동시키지 않는다. 승패 무관 메이드 효과는 조건 충족 시 발동한다.
- R2 RUN 자격은 각 RUN의 출전 카드·보드·사전 승률을 따로 사용한다. 타이브레이크는 능력 보상 및 연승 판정에 사용하지 않는다.
- 서버는 보드 생성 전에 raw 승률과 60% 자격을 `MatchResult`에 고정한다. 미리보기와 서버는 같은 결정적 계산·알려진 카드 입력을 사용하며, UI는 양 좌석 값을 각각 정수 내림한다. 따라서 raw 59.xx%는 60%로 표시되지 않는다. 재접속, 언어 전환, 숨겨진 미래 보드는 자격을 바꾸지 않는다.
- 이자/보상과 탈락 스냅샷 순서를 보존하여 탈락 라운드 이자는 없고, 최종 BB에는 실제 지급 내역만 반영한다.

## 사용자 승인 근거

- 카드 효과 문구 및 효과 범위: 사용자 제공 어빌리티 설명.
- Q 15BB 반값은 소수점 버림하여 7BB.
- 동급 최상위 BEST5에 조건 카드가 들어가는 조합이 있으면 타겟 스나이퍼를 인정하고 그 조합을 표시.
- 자본주의는 탈락한 라운드에 이자를 지급하지 않음.
- 승패 무관 메이드 효과와 승패형 효과의 Split/타이브레이크 경계를 분리.
