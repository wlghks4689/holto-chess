# 채용 관점의 문구·구성 검토 — 2026-10-16

## 발견한 문제

1. 첫 화면에 게임 슬로건이 앞서고 지원자의 담당 역할은 뒤에 있었다.
2. 추상적인 제목과 대칭형 문장이 반복돼 본문 내용을 예상하기 어려웠다.
3. 사례 안에서 개인 결정 패널과 문제·결정·검증 패널이 같은 내용을 다시 설명했다.
4. 결승 사례 제목은 UI 배치에 치우쳐 사용자 본인의 출전·공개 규칙 결정이 덜 보였다.
5. 직접 구현한 것으로 쓰지 않는다는 설명이 사례마다 반복돼 채용자가 기획 기여에 집중하기 어려웠다.

## 반영한 수정

- 첫 화면에서 게임을 한 문장으로 설명하고 게임 규칙·봇 행동 조건의 결정 및 Codex·Claude 활용을 명시했다.
- 소개 영역에 담당 기획과 협업 범위를 배치했다.
- 페이지 순서를 소개·역할 → 기획 사례 → 게임 규칙 → 작업 방식 → 관련 자료로 변경했다.
- 슬로건 대신 카드 구매, 카드 사용, 리롤, 출전·공개처럼 실제 행동을 제목에 썼다.
- 사례를 한 번의 설명 흐름으로 줄였다. 수치 해석의 한계는 결과와 함께 표시하고 상세 테스트·조건·근거 링크는 details에 배치했다.
- BB·리롤·포켓 페어·BURN을 필요한 곳에서 풀어 설명했다.
- 각 사례의 최초 제안·채택·세부 선택을 기존 근거에 맞게 유지했다. R2 실험은 개편 승인 뒤의 결과로 설명한다.
- 모바일에서는 사례 선택 버튼을 세로로 배치해 제목과 짧은 설명을 읽을 수 있게 했다.
