## 구현 요약

- **형식 구분과 호환**: 새 게임은 `sixRounds: true`를 저장한다. 이 표시가 없는 방(배포 시점에 진행 중인 방)은 기존 5라운드 규칙(R3 상점, R5 경매 결승)을 끝까지 쓴다. 라운드별 한도·상점 크기·최소 보유 장수는 `config.ts`의 `handLimitFor`, `minHandFor`, `purchaseLimitFor`, `rerollLimitFor`, `regularShopSizeFor`가 형식별로 돌려준다.
- **R3 경매**: 기존 경매 모듈을 그대로 쓰고 한도(`maxWins`, `minRaiseBB`)만 상태에 담았다. 입찰은 `startedAt`(안내 10초 뒤)부터 모두 동시에 열린다. 정산 뒤에는 단계를 유지한 채 3초 결과를 보여 주고, `finishCardAuctionReveal`이 낙찰 실패자만 드래프트 순서로 모아 기존 드래프트 화면에서 2배 가격 구매를 진행한다(`draft.priceMultiplier`).
- **R5 RUN IT THREE TIMES**: 새 단계 `OPPONENT_SELECT`와 동작 `CHOOSE_OPPONENT`를 추가했다. RUN 배치는 기존 `RUN_LOADOUT` 단계를 6장(RUN 1, 1, 2, 2, 3, 3)으로 확장했다. 매치 정산은 R2의 RUN 정산을 N회로 일반화해 같이 쓴다. 탈락 동점 타이브레이크는 기존 생존 타이브레이크에 RUN 핸드를 순서대로 넣는다.
- **R6 결승**: 상점 뒤 기존 배치 단계(`RUN_LOADOUT`)를 출전 5장 선택으로 재사용한다. 모두에게 가장 강한 5장을 미리 놓고, 5장을 넘게 가진 사람만 10초 동안 바꿀 수 있다(`setRunLoadout` 5장). 매치는 커뮤니티 보드 1개로 정산하고, BURN 카드(보유 − 출전)는 준비 화면과 연출에 공개한다(`burnCardIds`). 연출은 기존 보드 결승 경로를 3인용으로 고쳐(빈 4위 공개 구간 제거) R4 3-WAY 배치로 보인다.
- **강제 구매**: R5·R6 상점 시간이 끝나면, 모자란 좌석만 자기 상점에서 살 수 있는 가장 많은 장수(같으면 봇 평가가 좋은 조합)를 산다. 살 수 있는 카드가 없고 리롤이 남았으면 리롤한다. 장수가 충분한 좌석은 봇이 건드리지 않는다.
- **연출 비공개**: R5 RUN 카드는 그 RUN의 카드 교체가 끝난 프레임부터 서버가 보낸다. 해당 보드의 스트리트 판정(사용 카드 ID 포함)도 같은 시점까지 보내지 않는다. 테스트가 이 누출을 실제로 잡아 수정했다. 준비 화면에서 상대 카드는 뒷면만 보낸다.
- **화면**: 상대 선택 화면, RUN 3핸드 배치 화면, R3 경매 안내 팜플렛, R5 상점·배치의 "R5 상대" 배지, R5 연출(최신 RUN 보드가 위, RUN마다 점수판), R6 상점 7칸 모바일 배치, R6 출전 5장 화면(출전 줄 + BURN 줄, 족보 표시), R6 결승 3인 가로 배치 + 박스 안 BURN + 아래 보드, 6단계 라운드 진행 표시, 라운드 가이드·준비 헤더.
- **어빌리티**: 수치는 그대로, 결승 기준 효과는 R6로 옮겼다(쿼드 코어·언더독·독주자 결승). 프로텍터는 R1~R5(R5는 RUN마다), 퍼스트 클래스는 R3 2배 구매 순서에도 적용. 독주자 R6 값은 +8P(Claude 결정, 확인 필요).
- **봇**: R3 경매는 카드별 조합 점수(1~20, `auctionCardValue.ts`)와 점수별 지출 비율(공격적 곡선), 패 약함·탈락 위험·경쟁자 필요도·대안 가치로 최대 입찰가를 정해 경쟁하고, 상한을 넘으면 다른 카드로 옮긴다. 2배 구매는 오마하 프리플랍 강도로 빠르게 평가한다(2배 구매에서 15장 후보마다 샘플링하던 방식은 방을 멈출 만큼 느렸다). R5는 6장의 15가지 분할을 RUN 기대 승점(3:0 보너스 포함)으로 골라 강한 핸드를 RUN 1에 둔다. 1위 봇은 4위를 고른다.
- **문서·튜토리얼·가이드**: 게임 설명(초보자 가이드·규칙서) 한/영, 라운드 가이드, 튜토리얼 3·5장 재작성과 6장 신설. 튜토리얼 연습 시드 2634, 튜토리얼 진행 기록과 라운드 가이드 노출 기록은 초기화된다.
- **시뮬레이터**: 기본 6라운드, `--five-rounds`로 기존 규칙. R3 경매·2배 구매를 별도 구매 경로로 기록한다.

## 사용자 확인이 필요한 관찰

1. **봇끼리는 R3 2배 구매가 생기지 않았다.** 16장에 8명이라 누구든 기본가로 한 장을 확보할 수 있어, 봇 240명 전원이 경매로 카드를 얻었다(기본가보다 비싸게 낙찰 34건, 평균 +0.69BB). 사람은 입찰하지 않거나 마지막 몇 초에 밀려 다시 입찰하지 못할 때 2배 구매를 하게 된다. 2배 구매를 더 자주 보이게 하려면 카드 수를 줄이는 등의 조정이 필요하다.
2. **R5 역전 빈도**: R5 시작 시 승점 최하위가 R6에 진출한 게임은 30게임 중 3게임이다. 3:0 승리는 플레이어 기준 120명 중 10명(매치 기준 60건 중 10건)이다. 명세 의도(패자조 출신이 16점 차를 메울 수 있는 라운드)를 사람 플레이로 확인할 필요가 있다.
3. 독주자 R6 +8P, 대진 공개 3초, 1위 봇의 4위 선택 등 Claude가 정한 세부는 DECISIONS의 목록을 참고.
