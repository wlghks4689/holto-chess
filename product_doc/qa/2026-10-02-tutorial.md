# 체험 길라잡이 재구성 — 2026-10-02

## 확인한 문제

- 로컬 앱에서 직접 체험 진입. 첫 구매 전에 설명을 세 번 넘겨야 했고 R1 전체가 16단계였다.
- 모바일 고정 하단 안내가 화면 절반 가까이 차지하고, 쇼다운의 별도 족보 설명까지 중첩되었다. 목표 영역을 따라가는 딤/좌표 측정/자동 스크롤이 필요했던 구조였다.
- 실전 패널을 재사용하면서 보유 카드 중복, 작동하지 않는 20초 타이머, 이미 지나간 드래프트 순서, 비어 있는 히스토리가 연습에도 표시되었다.
- R2 마지막 설명의 onEnter가 leaveRoundResult를 호출해 결과 표를 보려는 단계에서 결과 페이즈를 먼저 벗어났다.

## 변경 범위

- chapters.ts / englishCopy.ts: 기본 6단계와 선택 연습 대본, 실제 규칙 유지, R2 결과 유지, R3 필요한 생존 타이브레이크 자동 정산. 영어 대본도 같은 동선으로 갱신.
- TutorialChapterMenu / TutorialApp / TutorialCoachmark / tutorial.css: 한 화면의 한 가지 목표, 단일 인플로 안내, 도움말 접힘, 완료 후 싱글 우선, 빈 카드와 카드 규격 통일, 7장 반응형, 연출 건너뛰기 및 재시도.
- TutorialSpotlight / useSpotlight: 사용처가 없어진 딤·좌표 추적 코드를 삭제. Git HEAD에서 복원 가능.
- RoundResults: 자식 매치 내용이 없으면 빈 히스토리 서랍을 만들지 않는다. 실전은 기존 자식 내용 유지.
- KO/EN locale: 새 안내 문구 추가, 사라진 UI의 미사용 문구 정리.
- 엔진, 밸런스, 싱글/멀티 규칙, 실전 타이머/공개 타임라인은 변경하지 않음.

## 회귀 검증

- 첫 단계 즉시 구매 및 기본 6단계, 대기/계속 클릭으로 ACT 건너뛰기 불가.
- 실제 구매로 준비 단계 진행, 판매 시 구매 단계 재개, 실제 리롤 비용, 재시도 시 카드 풀/BB/RNG 복원.
- R1~R5 모든 단계 도달/완료 및 카드 풀 무결성. 결과 안내 시 실제 결과 페이즈 유지, R3 최종 탈락 2명과 미해결 생존 경계 없음.
- R5는 3/5/7장 공개를 그대로 재생하되 각 공개마다 클릭하지 않음. 실제 렌더링 카드 수/체크포인트 검사.
- 빈 히스토리 제거 및 제공된 매치 내용 보존.
