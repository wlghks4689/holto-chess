# Ability Draft 공개 UX 검증

## 변경

- 선택된 카드 상세를 문서 흐름에서 분리한 native dialog로 표시. 내 카드 강조, 아이콘·이름·기존 효과 설명 사용.
- 선택된 슬롯을 같은 2:3 규격의 아이콘·이름·소유자 썸네일로 교체. 미선택 어빌리티는 서버에서 계속 비공개.
- 내 카드와 상대 카드 재열기, 닫기 버튼·Esc, 포커스 제한 및 배경 스크롤 잠금 지원.
- 싱글플레이 선택 순서별 컴포넌트 재생성을 없애 상세 팝업을 유지. 로컬 카운트다운만 순서별 초기화.
- 서버와 로컬 모두 전체 선택 후 30초 자동 공개 확인. 조기 READY는 기존 서버 정책대로 거부. 종료 안내 후 팝업을 정리하고 상점으로 전환.
- 서버 barrier key에 어빌리티 선택 횟수를 포함해 다음 플레이어에게 정상 제한시간 부여.

## 자동 검증

- `src/game/room.test.ts`, `src/game/abilities.test.ts`: 18개 통과. 즉시 공개 범위·미선택 덱 비공개·순서별 제한시간 초기화·30초 직전 전환 금지·마감 시 SHOP 전환 포함.
- `src/ui/AbilitySelectionPanel.test.ts`: 1개 통과. 10개 고정 슬롯, 내/상대 썸네일, 인라인 상세 카드 제거 확인.
- `tsc -b` 및 변경 TS/TSX 파일 eslint 통과.
- `npm run build` 통과: Cloudflare 타입 생성·클라이언트 및 Worker 타입 검사·프로덕션 번들.

## 브라우저 검증

- 360×780: 직접 선택 시 중앙 팝업, 내 카드 강조, 전체 공개 목록. document scrollWidth=360으로 가로 넘침 없음.
- 402×874: 상대의 긴 효과 설명·닫기 버튼이 화면 안에 표시.
- 1280×900: 중앙 팝업과 5열 카드 목록 확인.
- 내 상세 열린 상태에서 AI 선택 및 전체 공개 전환에도 상세 유지.
- 내 카드 재열기 → Esc 닫기 → 상대 카드 열기 성공.
- 30초 종료 시 열린 상세 정리 및 정상 상점 표시 확인.
- 브라우저 error 로그 없음.

캡처: `assets/ability-draft/modal-360.png`, `modal-402.png`, `reveal-360.png`, `reveal-desktop.png`.

## 검증 범위 제한

실제 iPhone Safari 기기와 여러 기기의 동시 온라인 접속은 실행하지 않았다. 모바일은 브라우저 CSS 뷰포트 검증이며, 멀티플레이 공개 정보와 진행 시간은 서버 room 테스트로 검증했다. 운영 배포는 하지 않았다.
