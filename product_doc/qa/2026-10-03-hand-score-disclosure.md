## 자동 검증

- 관련 5개 파일 57개 테스트 통과: 점수표/ShopCard/매칭 준비/점수 규칙/길라잡이 규칙.
- 후속 매칭 로딩 제외 반영 후 점수표·매칭 준비 21개 테스트 통과. 점수표 전용 12개 테스트는 10종 값/순서, 기본 접힘, R5 상점 전용, R1–R5 매칭 미노출, 비공개 카드 유지 검증을 포함한다.
- `npm run lint` 전체 통과. 후속 반영 후 `npx tsc -b --pretty false` 통과.
- `npm run build` 1회 통과. 관리자 관련 로컬 secrets 미설정 경고가 있었으며 배포는 하지 않았다. 이후 변경은 매칭 점수표 제거 및 짧은 화면 CSS 보정이며 최종 타입/테스트·실제 브라우저로 재확인했다.
- 전체 테스트: 병렬 기본 실행 중 시간 초과가 발생했고, 실행 중 후속 지시로 테스트와 컴포넌트가 변경되어 한 일시적 불일치도 발생했다. 이를 기존 게임 결함으로 단정하지 않는다. 실행을 중단하고 고정된 최종 소스로 앱 디렉터리에서 `npm test -- --maxWorkers=2`를 재실행해 **91개 파일 / 651개 테스트 전체 통과**(352.06초)를 확인했다.
- 최종 신규 컴포넌트·테스트의 ESLint와 `git diff --check`도 통과했다. Workers 테스트는 UI만 변경한 이번 작업에서 실행하지 않았다.
