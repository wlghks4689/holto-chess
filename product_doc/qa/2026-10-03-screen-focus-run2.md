# 화면 포커스·RUN 2 카드 교체·드래프트 정렬 보정 (2026-10-03)

## 원인과 수정

- 화면 전환의 `restoreGameViewport`가 `.page-shell`/`.cinema`에 tabindex=-1을 부여하고 포커스한다. 브라우저에서 상점 컨테이너의 기본 outline(auto 1px)을 확인했다. 이 비대화형 화면 앵커의 포커스 outline만 제거한다. 버튼·링크·툴팁의 키보드 포커스는 유지한다. 첨부의 파란 주석 선택선과 실제 포커스 테두리는 별개다.
- RUN 2 교체 구간은 OUT과 IN 모두 두 번째 카드를 닫아 두어 플랍과 함께 앞면으로 돌아갔다. IN 시작에 새 카드를 열고 기존 450ms 구간(420ms flip 완료)을 유지한 뒤 `CARD_SWITCH_SETTLE` 1000ms를 추가한다. 이 구간 RUN 2 보드는 revealed=0이다. 싱글·멀티 공용 시간표에 적용하고 presentation version을 12→13으로 갱신했다. 구버전 클라이언트에는 기존 버전 불일치 재접속 안내가 적용된다.
- PC R2/R4 헤더는 콘텐츠 폭과 space-between 정렬 때문에 제목이 카드 영역 중앙에서 벗어났다. 헤더/제목 행을 전체 폭으로 만들고 도움말 반대편에 같은 폭의 공간을 확보했다. 701px 이상에만 적용한다.
- 상점 잠금 버튼은 nowrap과 슬롯 최소 48px로 한 줄을 확보한다. 카드 본체 크기는 유지하고 슬롯 안에서 중앙정렬한다.

## 검증

- 타임라인 회귀 테스트를 먼저 추가해 미수정 코드에서 실패 확인, 수정 후 통과.
- RUN 2 IN/SETTLE에서 프로필 교체 카드 앞면과 보드 revealed=0을 검증하는 렌더링 테스트 추가.
- 관련 타임라인/렌더링/뷰포트/shared 4파일 59테스트, 게임 presentation 1파일 7테스트 통과(총 66).
- 앱·Worker 타입 검사, 전체 lint, 빌드 통과. 빌드의 로컬 관리자 secret 미설정 경고는 존재한다. 배포는 하지 않았다.
- 내장 브라우저: 능력 PICK/REVEAL 둘 다 컨테이너 outline none. PC 1440×900 R2/R4에서 제목과 카드 영역 중심 x=848로 일치. RUN 2 switch-in에서 모든 프로필 카드 앞면, RUN 2 보드 5장 뒷면 확인.
- 360×660 상점 document scrollHeight=660, 잠금 버튼 48px·nowrap·텍스트 넘침 없음. 402×874도 확인.
- 전체 일반 테스트/Worker 전용 테스트 및 실제 iPhone·실제 멀티 접속 플레이는 이번 작업에서 재실행하지 않았다. RUN 2 1초 간격은 공용 타임라인 회귀 테스트로 검증했고 실시간 실기기 재생은 미검증이다.
- 기존 미커밋 변경 보존. 커밋·푸시·운영 배포 없음.
