# R2·R5 RUN 이동 순서와 PC 완료 보드 배치

사용자 요청: 이전 RUN 패널이 하단으로 완전히 이동한 뒤 다음 RUN의 보드를 진행하고, PC의 R5 완료 화면에서는 세 RUN 패널이 커뮤니티 보드 영역을 균등하게 사용한다.

## 변경

- 공통 재생 시간표에 `RUN_TRANSITION` 640ms를 추가했다. 기존 패널 이동 560ms와 80ms의 정리 시간을 먼저 사용한 뒤 R2 플랍 또는 R5 카드 교체를 시작한다. 기존 결과 읽기 시간과 플랍·턴·리버 공개 속도는 유지한다.
- 이동 중에는 이전 RUN의 손패를 유지하고 다음 보드는 모두 닫아 둔다. 서버 공개 projection도 새 R5 손패를 이동 중 공개하지 않는다. 새 시간표는 서버와 클라이언트가 함께 사용하며 presentation version은 20이다.
- 늦게 도착한 프레임은 남은 이동 시간만 사용한다. 이동 구간을 이미 지난 프레임에서는 뒤늦은 이동 애니메이션을 시작하지 않는다. 감소된 모션 설정과 catch-up 화면은 기존 즉시 배치를 유지한다.
- 기존 PC 가로 레이아웃 범위(폭 1200px 이상, 화면 비율 4:3 이상)에서 R5의 결과 단계에 완료 RUN을 같은 flex 비율로 배치한다. 진행 중인 RUN과 모바일 배치는 기존 크기 규칙을 사용한다. R2 PC 결과 배치는 원래 설정을 유지한다.
- 후속 요청 반영: 상세보기는 RUN 박스 안쪽 전체를 덮는다. 두 손패의 가로 배치와 아래 커뮤니티 카드 한 줄을 유지하고 두 카드 행 사이에 PC 18–28px, 모바일 12px 간격을 둔다. 좁은 화면에서도 카드 행을 세로 한 줄로 바꾸지 않는다.
- `COMPLETED`는 플레이어 기준 `WIN` / `LOSS`로 교체했다. 무승부는 `DRAW`, 관전자에게는 `RESULT`로 표시해 다른 플레이어의 승패를 자신의 결과처럼 표시하지 않는다. 기존 PC 전용 캡션 위치를 유지한다. 스코어 표 양쪽 닉네임은 모든 화면에서 16px이다.

## 검증

- 타임라인·SSR 렌더링·RUN 순서·승률·서버 공개·공유 일정: 6파일 82테스트 통과. 이동 구간 전체에서 다음 RUN 보드 및 새 R5 손패가 숨겨져 있고 다음 동작은 이동 종료 뒤 시작하는 회귀를 포함한다.
- Cloudflare 실제 로컬 런타임 공개 일정: 1파일 3테스트 통과.
- TypeScript app/worker, 변경 소스 ESLint, 프로덕션 빌드 확인.
- PC 1440×900: 세 완료 패널 각각 226.72px, 보드 영역 하단과 마지막 패널 하단 모두 872.98px.
- PC 1366×768: 세 패널 187.42 / 187.42 / 187.41px. 보드 영역 하단 743px까지 채움. 1px 미만의 차이는 소수점 픽셀 배분이다.
- 모바일 393×852: 가로 overflow 없음. R5 완료 보드와 손패·닉네임 배치 시각 확인.
- `tools/perf/game-transition.html`에서 실제 엔진 fixture와 production 컴포넌트를 재생하고 `runMoves`를 기록한다. `openDuringMove=0`, `movingAtNext=0`으로 이동과 다음 동작이 겹치지 않는지 확인한다. online 모드는 서버 시계·공개 projection 재생이며 실제 회선 부하 검증과 구분한다.
- R2 모바일 local / PC server-clock, R5 PC local / 모바일 server-clock의 4개 재생에서 총 6번의 RUN 이동을 관측했다. 모든 이동 중 다음 보드 열린 카드 0장, 다음 동작 시작 시 진행 중인 이동 애니메이션 0개, 브라우저 오류 0개. [측정 기록](2026-10-16-run-board-transition.json).
- 마지막 진행 문구 숨김 후 관련 3파일 61테스트 재확인. 최종 CSS와 표시 소스 lint 및 production 번들 생성 통과.
- 후속 UI 확인(1440×900): RUN 박스 547.55×226.72px, 상세보기 545.55×224.72px로 부모 테두리 1px 안쪽을 모두 채움. 손패–보드 간격 23.39px, 닉네임 두 개 모두 16px, 결과 캡션 LOSS / WIN / WIN, 가로 overflow 없음. 상세보기/결과 문구 렌더링 52회귀와 타입·lint 확인.
- 모바일 393×852 후속 확인: 상세보기 357×116.97px로 부모 안쪽 전체를 채움. 카드 행 간격 12px, 손패 가로 배치, 닉네임 16px, 가로 overflow 없음. [모바일 상세보기](assets/2026-10-16-r5-detail-mobile.png).
- 추가 모바일 요청: 종료된 RUN의 보드 카드를 프로필 손패와 같은 43×61px(레이아웃 정수 크기), 같은 숫자/무늬 글자 크기로 맞췄다. 375×667 및 393×852 모두 프로필 닉네임 12px, 프로필 높이는 변경 전후 318.23px로 동일하고 가로 overflow 없음. 상단 스코어 표 닉네임의 16px은 유지한다. PC 1440×900의 기존 카드 폭 74px·프로필 닉네임 19.008px·프로필 높이 701.16px도 동일함을 확인했다. [모바일 카드 규격](assets/2026-10-16-r5-mobile-matched-cards.png).
